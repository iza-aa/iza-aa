## 🏛️ Core Engineering Tenets (How I Build)

1. **Defensive AI Architecture:** LLMs are powerful reasoning engines but unreliable storage backends. Every AI agent I build enforces strict mathematical validation layers (Zod schemas, 3-tier regex balancers, untrusted perception tagging) before any state enters a database.
2. **Crash-Only Process Supervision:** Long-running agents will fail. Rather than relying on fragile in-memory try/catch blocks, I design decoupled supervisor-worker loops with database heartbeats and automated circuit breaking.
3. **Auditability & Traceability by Default:** From campus IT hardware to restaurant financial registers and government nutrition budgets, every state mutation requires immutable audit logs and idempotent execution.

## 🚀 Flagship Systems & Production Architectures

### 1. [iza-sppg-agent](https://github.com/iza-aa/iza-sppg-agent) · *Applied AI & Financial Agent*
- **The Problem:** Reconciling hundreds of physical grocery receipts with strict government catering budgets (Badan Gizi Nasional SPPG/MBG).
- **The Architecture:** Autonomous multimodal Gemini Vision extraction pipeline paired with Zod schema validation, automated circuit breaking, and bidirectional atomic cell synchronization to Google Sheets.
- **Proof of Rigor:** **33 automated test suites · 213 passing test cases (Vitest) · 36,000+ LOC TypeScript**.

### 2. [iza-wa-agent](https://github.com/iza-aa/iza-wa-agent) · *Forward Deployed Commerce Agent*
- **The Problem:** Bringing enterprise conversational commerce to non-technical Indonesian MSME owners over WhatsApp.
- **The Architecture:** Baileys multi-device socket protocol engine with 3-tier regex anti-leak parsing guardrails (guaranteeing zero raw JSON leaks), sliding-window transaction deduplication, and automated human cashier handover.
- **Proof of Rigor:** **248 production git commits · 14 test suites · 115 passing tests**.

### 3. [iza-pos-v2](https://github.com/iza-aa/iza-pos-v2) · *Cloud Restaurant POS & Operations Platform*
- **The Problem:** Point of sale reliability during 12-hour high-volume cashier shifts and preventing staff attendance fraud.
- **The Architecture:** Next.js 15 App Router platform with self-service QR table ordering, tamper-resistant geofenced staff attendance kiosks (server-side Haversine validation), live Supabase WebSocket queues, and proactive JWT session refresh middleware.
- **Proof of Rigor:** **94,000+ LOC TypeScript · 114 App Router routes · Full PWA & Web Push**.

### 4. [izanotch](https://github.com/iza-aa/izanotch) · *Local-First macOS Desktop Agent & MCP*
- **The Problem:** Autonomous computer-use agent execution integrated with native hardware display geometries.
- **The Architecture:** Tauri 2 and Rust native shell backed by a background Swift XPC daemon tracking MacBook display notch boundaries, paired with an Anthropic Model Context Protocol (MCP) tool bridge and multi-layer prompt injection defense.
- **Proof of Rigor:** **49,000+ LOC Swift & Rust · Native XPC Helper · GitHub Actions macOS-15 runner**.

### 5. [bsirelay](https://github.com/iza-aa/bsirelay) · *Developer Tooling & MCP Harness Framework*
- **The Problem:** Fragmented AI coding agent configurations across 15+ modern harnesses (Cursor, Devin, Gemini CLI, OpenCode).
- **The Architecture:** Zero-dependency Node.js standard-library CLI and MCP relay server standardizing team memory, guidelines, and Chrome DevTools Protocol design inspection into a single synchronization command.
- **Proof of Rigor:** **v1.2.0 production release · Python & TypeScript test suites**.

### 6. [hidrolux](https://github.com/iza-aa/hidrolux) · *Industrial Engineering Corporate Showcase*
- **The Problem:** Presenting complex industrial water purification plant engineering (Reverse Osmosis, Ultrafiltration) to commercial B2B procurement decision-makers.
- **The Architecture:** Next.js App Router corporate platform with interactive filtration diagrams and quote funnels.
- **Proof of Rigor:** **Live in Production: [hidro-phi.vercel.app](https://hidro-phi.vercel.app)**.
