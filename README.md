## 🚀 Featured Systems & Production Architectures

### 1. [iza-pos-v2](https://github.com/iza-aa/iza-pos-v2) — Cloud Restaurant Operating System & Store Management
- **Scope & Scale:** End-to-end POS and restaurant operations platform spanning **94,000+ lines of TypeScript and 114 App Router routes**.
- **Selling Points:** Self-service QR table ordering, live kitchen command center (Supabase Realtime websockets), automated register closing & bookkeeping, tamper-resistant staff attendance kiosks (server-side Haversine geofence verification), and owner analytics snapshot engines (live COGS, gross margin, and stock alerts). Includes offline PWA capability and proactive JWT refresh middleware.
- **Stack:** Next.js 15, React 19, Supabase PostgreSQL (RLS), Tailwind CSS, Turbopack · [Live Demo](https://iza-pos-v2.vercel.app)

### 2. [iza-sppg-agent](https://github.com/iza-aa/iza-sppg-agent) — Autonomous Multimodal Financial & Auditing Agent
- **Scope & Scale:** Autonomous financial intelligence agent for school nutrition catering vendors under Badan Gizi Nasional (MBG). Built with **36,000+ LOC TypeScript**.
- **Selling Points:** Ingests raw wrinkled paper receipts via Gemini Vision, validates math and budget ceilings with Zod schemas, supervises processes with crash-only auto-recovery heartbeats, executes atomic two-way synchronization to Google Sheets (6 tabs), and generates official legal audit PDF statements (SPJ) on demand.
- **Stack & Rigor:** Node.js, Grammy Telegram, Gemini 2.5 Flash, Supabase, Google Sheets API · **33 test suites · 213 automated passing tests (Vitest)**

### 3. [iza-wa-agent](https://github.com/iza-aa/iza-wa-agent) — Enterprise WhatsApp Conversational Commerce Engine
- **Scope & Scale:** Full-lifecycle conversational commerce and automated bookkeeping platform for Indonesian MSMEs across **248 production git commits**.
- **Selling Points:** Connects directly to WhatsApp multi-device protocols via Baileys sockets. Ingests Indonesian voice notes, receipt photos, and informal chat, passing through a 3-tier regex guardrail that guarantees zero raw JSON leakage into customer chats. Features sliding-window duplicate transaction detection, multi-department PDF bank statements (Kitchen, Barista, Cashier), and automated handover to human cashiers.
- **Stack & Rigor:** TypeScript, Baileys Socket Engine, Gemini Multimodal, Supabase · **14 test suites · 115 passing tests** · [Live Webhook](https://iza-wa-agent.vercel.app)

### 4. [izanotch](https://github.com/iza-aa/izanotch) — Local-First macOS AI Desktop Companion & Computer-Use Engine
- **Scope & Scale:** Native macOS desktop companion and automation agent built across **49,000+ lines of Swift native and a Tauri 2 / Rust shell**.
- **Selling Points:** Hardware-aware architecture tracking physical MacBook notch display boundaries via a dedicated Swift XPC daemon. Exposes screen perception and accessibility controls through Anthropic's Model Context Protocol (MCP) SDK, backed by a multi-layer prompt injection defense engine that tags untrusted third-party screen content in real time.
- **Stack:** Swift (AppKit & XPC), Tauri 2, Rust (2024 Edition), React 19, Model Context Protocol (MCP)

### 5. [bsirelay](https://github.com/iza-aa/bsirelay) — Multi-Harness MCP Relay & Developer Tooling Framework
- **Scope & Scale:** Production developer tooling suite created for enterprise engineering teams at Badan Sistem Informasi (BSI).
- **Selling Points:** Zero-dependency Node.js CLI binary and Model Context Protocol (MCP) relay standardizing guidelines, memory, and rules across 15+ modern AI coding environments (Cursor, Devin, OpenCode, Gemini CLI). Includes Chrome DevTools Protocol (CDP) visual design token extractors and automated environment diagnostics (`bsirelay doctor`).
- **Stack:** TypeScript, Node.js Standard Library, Python CDP Tools · Production Release v1.2.0

### 6. [hidrolux](https://github.com/iza-aa/hidrolux) — Industrial Water Treatment Engineering Platform
- **Scope & Scale:** Corporate technical marketing and specification platform engineered for an industrial water purification and filtration equipment company.
- **Selling Points:** Simplifies complex chemical and physical filtration parameters (Reverse Osmosis desalination plants, Ultrafiltration skids, wastewater effluent systems) into interactive high-trust B2B procurement specifications and quote conversion funnels.
- **Stack:** Next.js App Router, React 19, Tailwind CSS, Shadcn UI · [Live Platform](https://hidro-phi.vercel.app)
